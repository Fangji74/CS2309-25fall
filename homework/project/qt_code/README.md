# 项目说明
## 运行环境
 - Windows环境
## 库依赖
 - 无
## 使用说明
 - 打开deploy文件夹，点击运行project_node_draw.exe
 - 点击菜单栏文件-打开文件-选择目标json文件
 - ctrl+鼠标滚轮或者点击菜单栏视图-放大/缩小，可以更改视图大小
 - 鼠标悬浮于节点上可以显示节点id等信息，左键按住可以进行拖动
 - 鼠标点击边可以显示边对应属性，点击菜单栏-显示箭头，可以选择是否显示箭头
## 拓展方向
 - 将子图模块提取直接集成至窗口中（使用Qt C++重写一遍原graph_extractor即可）
 - 拓展同属性线高亮显示，额外添加自环显示，添加节点更详细的属性显示
 - 根据图的层次化结构进行绘图
 - 优化文件组织架构，将graph_viewer.cpp中不同种类功能拆分开来
